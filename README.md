# Bitburner Full Stack

A clean-sheet automation stack targeting Bitburner **3.0.1**, with in-game scripts and potential companion application capabilities. No legacy code is inherited.

## Current phase
Capability discovery and requirements planning. Architecture, implementation language, and companion dependency are not yet decided.
